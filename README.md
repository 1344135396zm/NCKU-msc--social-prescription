# 社會處方資源站

整合社區資源的簡單網站，給兩種人使用：

- **民眾 / 家屬**：用「你最近想要什麼？」的問題找資源，加入「我的清單」後可以列印。
- **Link worker / 醫療人員 / 社工**：用完整篩選找資源，開「社會處方單」（含個案目標、備註、追蹤日期），可以列印或存成 PDF。

技術：純 HTML + CSS + JavaScript，沒有框架、沒有後端、不需要安裝任何東西。網站不蒐集個資，清單只存在使用者自己的瀏覽器中。

## 檔案

| 檔案 | 用途 |
|---|---|
| `data.csv` | **資源資料**，平常只需要改這個 |
| `config.js` | 設定：資料來源網址、需求類別、資料過期月數 |
| `index.html` / `style.css` / `app.js` | 網站本身 |

## 在自己電腦上預覽

瀏覽器不允許直接雙擊打開的網頁讀取 CSV，所以要開一個本機伺服器：

```bash
cd social-prescribing
python3 -m http.server 8000
```

然後打開 http://localhost:8000

## 編輯資源資料

用 Excel、Numbers 或 Google 試算表打開 `data.csv` 編輯，存檔時選 **CSV（UTF-8）**。

| 欄位 | 說明 |
|---|---|
| `id` | 每筆資料不重複的代號，例如 `east-garden-1`。建立後不要改，否則別人清單裡的這筆資源會消失 |
| `name` | 名稱 |
| `category` | 類別，可以填多個，用「、」分隔：社會連結、身體活動、藝文學習、自然綠色、心理支持、生活協助、照顧者支持 |
| `audience` | 適合對象，例如 不限、高齡者、大學生、照顧者 |
| `district` | 行政區。填 `全國` 或 `線上` 的資源，不論選哪一區都會顯示 |
| `address` | 地址（會自動產生地圖連結） |
| `time` | 時間 |
| `cost` | 費用。有「免費」兩個字就會被歸類為免費 |
| `signup` | 報名方式 |
| `contact` | 聯絡方式（電話會自動變成可撥打的連結） |
| `website` | 網址 |
| `accessibility` | 無障礙資訊 |
| `description` | 用白話寫的簡短介紹（民眾會看到） |
| `source` | 資料來源 |
| `verified_date` | 最後確認日期，格式 `2026-10-05`。空白或超過 6 個月，會在 Link Worker 模式顯示「需重新確認」 |

> `data.csv` 中的全國專線是真實資料，但服務時間和收費仍請在上線前逐一確認，並填入 `verified_date`。標示 **【範例】** 的資料是假的，上線前請刪除或替換。

### 改用 Google 試算表（推薦給多人維護）

1. 把 `data.csv` 匯入 Google 試算表（第一列欄位名稱不要改）
2. 檔案 → 共用 → **發布到網路** → 選該工作表、格式選「逗號分隔值 (.csv)」→ 發布
3. 把得到的網址貼到 `config.js` 的 `dataUrl`

之後只要編輯試算表，網站重新整理（約幾分鐘內）就會更新，不需要改程式。

## 上線（免費）

**GitHub Pages**：建立 GitHub repository，上傳所有檔案 → Settings → Pages → Branch 選 `main` → Save，幾分鐘後就會有網址。

也可以用 Netlify：把整個資料夾拖進 https://app.netlify.com/drop。
